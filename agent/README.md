# Agent-Systems-Guide

> 从最小 Agent Loop 到可评测、可恢复、可审计的智能体系统：一套中文、项目驱动的 Agent 学习教程。

本教程沿用当前仓库 AI Infra 教程的组织方式，将**正文、实验、项目、自测和资料导航**放在一条学习主线上。内容独立编写，不复制 Datawhale 或其他课程正文；参考来源与扩展阅读集中见[参考资料与扩展资源图谱](resources/README.md)。

## 项目简介

Agent 不是“给大模型加一个角色提示词”，而是一个在环境中持续**观察、决策、调用工具、接收反馈并更新状态**的系统。模型只是决策组件；工具协议、上下文、权限、状态、执行环境、评测和运维共同决定系统是否可用。

本教程以 LLM Agent 为主要对象，同时保留工作流、分布式状态和软件工程基础。学习重点不是记住所有框架，而是能从零实现核心机制，再读懂真实框架的取舍。

## 你将学到什么

- 区分 chatbot、确定性 workflow、单 Agent 与多 Agent，并知道何时不该使用 Agent。
- 实现结构化输出、工具调用、ReAct 循环、停止条件、预算和错误处理。
- 设计工具契约、任务规划、记忆分层、上下文压缩和带引用的 RAG。
- 理解 checkpoint、幂等、人工中断、MCP、A2A、Skills 与多 Agent 编排。
- 建立任务集、轨迹评测、pass@k/pass^k、trace、SLO 和单位成功成本。
- 防御提示注入、越权工具调用、数据外泄和记忆污染，完成可复现的综合作品。

## 适合谁

适合会基本 Python、了解 HTTP/JSON 和大模型基本概念的学生、算法工程师、后端工程师与系统工程师。不要求 GPU，也不要求先学 CUDA 或模型训练。完全零基础读者先完成[第 00 章](docs/00-如何使用本教程.md)中的前置补给。

## 快速开始

1. 阅读[学习路线](ROADMAP.md)，选择标准、冲刺或研究方向路线。
2. 按顺序阅读 `docs/`；每章先完成“最低实践”，再做扩展任务。
3. 无模型 API 时先运行本教程的离线实验：

```bash
python code/ch02/structured_output.py
python code/ch03/mini_agent.py
python code/ch05/dag_planner.py
python code/ch06/memory_context.py
python code/ch07/rag_lab.py
python code/ch08/checkpoint_runner.py
python code/ch12/eval_metrics.py
python code/ch13/trace_metrics.py
python code/ch14/policy_gate.py
python -m unittest discover -s tests -v
```

4. 有模型 API 后，再把第 03 章的模拟模型替换为真实模型适配器。密钥只放在环境变量或密钥管理工具中，不写入代码、日志和 Git。
5. 用 `templates/` 记录笔记、实验、评测任务和源码阅读，最后完成 `projects/` 中的阶段项目。

## 学习闭环

```text
概念 -> 最小实现 -> 构造任务集 -> 测量 -> 分析失败 -> 阅读真实源码 -> 复盘
```

每章只有同时做到以下三点，才算完成：

- **能解释**：不用框架黑话，说清机制解决什么问题、何时无效。
- **能验证**：给出任务、配置、轨迹、对照组、成功标准和限制。
- **能迁移**：面对新模型、新工具或新业务，能重新设计并评测。

## 重要说明

- 离线实验用于验证解析、控制流、检索、状态和评测逻辑，不代表真实模型的任务成功率。
- Agent 评测必须绑定模型、提供方、版本、提示词、工具集、环境快照、采样参数和运行日期；不要把其他团队的榜单数字直接当作自己的结论。
- 框架与协议迭代较快，正文讲稳定机制，具体 API 和版本以官方文档为准。
- 外部网页、文档、邮件、工具描述和检索结果都应视为不可信输入，不能因进入上下文就获得指令权限。
- 所有上游代码、数据、模型和文档的许可证分别以其官方仓库为准。
